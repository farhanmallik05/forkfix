# Forkfix Evaluation Suite

This directory contains the SWE-bench Verified 30-task evaluation harness, baseline comparison runners, and metrics computation scripts.

## Contents
- `run_benchmark.py`: Executes the 30-task slice across Forkfix (Multi-Tier) and the Single-Branch Ultra baseline.
- `tasks/`: Task definitions, issue descriptions, and ground-truth validation manifests.
- `results/`: Output JSON summaries, cost breakdowns, and pass/fail tables.
